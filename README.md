# Cozy Cup Coffee — Website

A responsive, four-page static coffee shop website built with **HTML, CSS, and vanilla JavaScript**. Ready to upload to a GitHub repository and publish with GitHub Pages.

## Pages
- `index.html` — home page with oversized cafe interior hero
- `menu.html` — sample menu and Philippine peso prices
- `shophours.html` — weekly schedule
- `contactus.html` — validated inquiry form (front-end demo only)
- `css/style.css` — shared responsive styling
- `js/main.js` — mobile navigation, copyright year, and form validation

## Preview locally
Open `index.html` in a web browser. Use the navigation to move between pages.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example `cozy-cup-coffee`).
2. Upload all files and folders **from inside** this ZIP to the repository root, preserving the `css/` and `js/` folders.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
5. Your site will appear at `https://YOUR-USERNAME.github.io/cozy-cup-coffee/` after GitHub publishes it.

## Before going live
- **Contact form:** This is a demonstration. It validates fields but **does not send or save submissions**. Connect it to a secure form handler (e.g. Formspree, Netlify Forms, or your own server), add spam protection, and publish a privacy notice.
- **Photos:** The site references Unsplash images via remote URLs. An internet connection is required to load them. Confirm image usage terms, availability, and replace with your own licensed photos if preferred.
- **Business details:** The Metro Manila location, email `hello@cozycup.example`, opening hours, menu, prices, and founding year are illustrative placeholders. Replace them with real business details before launch.
- **Brand:** The coffee-cup icon is an emoji-based logo for demonstration. Replace it with a custom SVG/PNG logo if you have one.

## Responsive breakpoints
Desktop, tablet (up to 1000px), mobile (up to 760px), and compact phones (up to 480px). Mobile includes a collapsible navigation menu.
